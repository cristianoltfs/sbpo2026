# sbpo2026

artigo

Utilizando Debian 13 com o OpenJDK25

=====================

Utilizar o arquivo de imagem na mesma pasta do .cfg

Utilizar imagem .obj em formato .zip

Obs: trabalhar com .dae no JaamSim é melhor que .obj, porém o .dae pode ser mais complexo de encontrar

=====================

sempre executar o JaamSim na pasta onde está o cfg já chamando o arquivo cfg no comando

colocar as imagens (.zip) na mesma pasta do cfg

exemplo:

user@pc:~/sbpo2026$ java -jar JaamSim2026-02.jar modelo02.cfg
